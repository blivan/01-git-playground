
# Git Playground

一个用于学习 Git、GitHub 和现代软件工程协作流程的 Python 示例项目。

## 项目目标

通过一个最小 Python 项目，实践版本管理、分支协作、代码审查和自动化测试。

## Features

- Python 基础功能实现
- Git 版本管理实践
- GitHub 远程仓库管理
- 分支与合并实践

## Requirements

- Python 3.12+

## Getting Started

克隆项目：

```bash
git clone <repository-url>
```

运行程序：

```bash
python main.py
```
